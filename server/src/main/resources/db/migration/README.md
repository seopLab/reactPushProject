# DB 마이그레이션 (Flyway)

서버가 켜질 때 이 폴더의 SQL 을 번호 순서대로 한 번씩 실행해서 테이블을 만든다.

- 파일 이름: `V{번호}__{설명}.sql` (밑줄 2개) — 예: `V1__init.sql`, `V2__add_favorite.sql`
- **ERD 확정 후 첫 파일은 `V1__init.sql`**
- 이미 적용된(main 에 합쳐진) 파일은 **절대 수정하지 않는다.** 바꿀 게 있으면 다음 번호 파일을 새로 만든다
- 같은 번호를 두 명이 동시에 만들면 충돌한다 → 새 파일을 만들기 전에 팀 채널에 번호를 먼저 말하기
- `application.yml` 의 `ddl-auto: validate` 때문에, 엔티티와 테이블이 다르면 서버가 안 켜진다 (일부러 그렇게 둠)
